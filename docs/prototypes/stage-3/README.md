# Stage 3 — Hybrid Review Screenshots

Captured 17 November 2026 from the local prototypes in Chrome at 1440 × 1000 desktop and 390 × 844 mobile (mobile images are 375 px wide because of the scrollbar). The hero, origin, footer and mobile shots were re-captured after the light-colour refinement (D-024, CSS v7). The menu shots were re-captured on 18 November 2026 after the three-image menu gallery was added (D-026, CSS v8).

## Notes

- Stage 4 production planning is documented in [`../../production/README.md`](../../production/README.md): stack, CMS, deployment, QA and launch plan.
- The light-colour refinement (D-024) adds a porcelain hero info ribbon in both themes, a smoked-limestone origin section that stays light in dark mode, and a porcelain hybrid/menu footer in light mode. Dark mode keeps its obsidian footer.
- The menu now opens with a full-bleed three-image gallery: kebab/plate, pizza and baklava, each marked "Symbolbild" / "Placeholder". The existing pide band remains below the first three categories. All four are stock placeholders, not ALMAS food.
- Food photography is licensed Unsplash stock, not ALMAS food. It is marked as placeholder in the pages and must be replaced before launch.
- Opening hours are intentionally absent. The client has not supplied verified hours.
- Social buttons are visibly disabled placeholders until the client provides Instagram, Facebook and TikTok URLs.
- Prices and descriptions are the 60 verified items transcribed from the printed menu; confirm changes before publication.
- The map is an OpenStreetMap embed using the confirmed address coordinates.
